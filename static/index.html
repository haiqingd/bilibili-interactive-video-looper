      HOW IT WORKS

      看懂每一次选择

      解析器先读取视频信息与剧情图版本，再逐片段读取选项、条件和变量更新。每个片段仅采集一次，所有分支都会保留，包括条件暂不成立的选项。

      攻略使用「片段 + 当前问题 + 累积变量」搜索，最少步骤包含自动跳转。含环区域表示图结构有循环；确认闭环表示某个可达状态进入后无法退出。默认使用精简流程，也可切换章节总览，循环区域和连续片段可以逐层展开，原始数据仍保留。加分循环会继续探索，不会仅凭片段重复就停止。状态去重只区分后续仍会读取的变量，攻略仍保留完整评分记录。自动跳转不展示手动选择文字。

      随机变量、未知表达式、访问失败和搜索上限会标记为待验证。只有完整状态搜索下才保证全结局与最短性；部分结果的路线是当前已验证路径。

      当前上限：1,500 个采集片段、20,000 个状态、300 次选择转换。支持逻辑、比较、算术和分号分隔的变量赋值，不执行来源数据中的代码。登录状态和分数初值以入口接口返回为准。

      攻略库保存在本机 SQLite；导出 JSON 保留原始节点响应，可重新导入。示例为虚构故事，与输入的视频无关。服务默认仅监听本机。
